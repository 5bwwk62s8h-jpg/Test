# Калькулятор ожидаемых затрат по ФОТ

Программа на Python для расчёта ожидаемых затрат по фонду оплаты труда (ФОТ)
за месяц с учётом:

- **нормы рабочего времени** — по упрощённому производственному календарю
  (40-часовая неделя, нерабочие праздничные дни, сокращение на 1 час
  предпраздничных рабочих дней);
- **отпусков** — оклад за отработанное время уменьшается пропорционально
  пропущенным рабочим часам, отдельно рассчитываются отпускные исходя из
  среднего дневного заработка и календарных дней отпуска (нерабочие
  праздничные дни в период отпуска не оплачиваются, ст. 120 ТК РФ);
- **премий** сотрудников — фиксированной суммой, процентом от оклада или
  процентом от начисления за фактически отработанное время;
- (опционально) **страховых взносов** работодателя — процент от начисленной
  суммы.

## Установка

Зависимостей вне стандартной библиотеки Python не требуется. Для запуска
тестов нужен `pytest`:

```bash
pip install pytest
```

## Использование

Список сотрудников описывается в JSON-файле (пример — `examples/employees.json`):

```json
[
  {
    "id": "1",
    "name": "Иванова Анна Сергеевна",
    "oklad": 120000,
    "rate": 1,
    "vacations": [
      {"start": "2026-08-10", "end": "2026-08-23"}
    ],
    "premium_type": "percent_worked",
    "premium_value": 20,
    "avg_daily_earning": 3800
  }
]
```

Поля:

| Поле | Обязательно | Описание |
|---|---|---|
| `id`, `name` | да | Идентификатор и имя сотрудника |
| `oklad` | да | Оклад за полную норму при ставке 1.0 |
| `rate` | нет (по умолч. 1) | Ставка: 0.5, 1.0, 1.5 и т.д. |
| `vacations` | нет | Список периодов отпуска `{"start": "YYYY-MM-DD", "end": "YYYY-MM-DD"}` |
| `premium_type` | нет (`fixed`) | `fixed` — фикс. сумма, `percent_oklad` — % от оклада, `percent_worked` — % от начисления за отработанное время |
| `premium_value` | нет (0) | Сумма или процент премии, в зависимости от `premium_type` |
| `avg_daily_earning` | нет | Средний дневной заработок для расчёта отпускных. Если не указан, оценивается как `oklad * rate / 29.3` |

Запуск расчёта за текущий месяц:

```bash
python -m payroll_calculator.cli --employees examples/employees.json
```

Запуск за конкретный месяц, со страховыми взносами и выгрузкой в CSV:

```bash
python -m payroll_calculator.cli \
  --employees examples/employees.json \
  --year 2026 --month 8 \
  --insurance-rate 30.2 \
  --csv report.csv
```

Все опции CLI:

```
--employees PATH        JSON-файл со списком сотрудников (обязательно)
--year YEAR              Год (по умолчанию — текущий)
--month MONTH             Месяц 1-12 (по умолчанию — текущий)
--insurance-rate RATE    Ставка страховых взносов работодателя, % (по умолчанию 0)
--holidays PATH          Свой файл праздничных/предпраздничных дней
--csv PATH                Сохранить отчёт также в CSV
```

## Производственный календарь

Праздничные и предпраздничные дни хранятся в
`payroll_calculator/data/holidays_ru.json` для 2024-2027 годов и не
учитывают ежегодный перенос выходных дней постановлением Правительства РФ.
Для точного соответствия официальному производственному календарю на
конкретный год отредактируйте этот файл или передайте свой через
`--holidays путь/к/файлу.json` (формат такой же).

## Структура проекта

```
payroll_calculator/
  models.py               # Employee, VacationPeriod, PremiumType
  production_calendar.py  # норма часов/дней за месяц
  calculator.py            # расчёт затрат по сотруднику и по месяцу
  data_loader.py           # загрузка сотрудников из JSON
  report.py                # текстовый и CSV отчёт
  cli.py                    # точка входа командной строки
  data/holidays_ru.json    # праздничные/предпраздничные дни
examples/employees.json    # пример входных данных
tests/                      # тесты pytest
```
